Rest periods are easy to ignore, yet they shape how much work the next set can hold.

## Heavier and multi-joint: rest longer

For heavy compound lifts — squats, deadlifts, presses, rows — **2 to 3 minutes** (sometimes more) usually lets the next set match the last one.

## Lighter and single-joint: rest shorter

For isolation work such as curls, raises or extensions, **60 to 90 seconds** is often enough.

## A simple test

If the reps drop sharply from one set to the next at the same weight, the rest was probably too short. Resting a little longer is a cheap way to do more quality work in the same session.

## Use a timer

Rest tends to stretch when there is a phone in hand, and shrink when the gym is busy. A rest timer that starts the moment a set is marked done keeps it honest.
