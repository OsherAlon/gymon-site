Memory is a poor training partner. A log remembers exactly what happened, set by set.

## What to record

For each set: **the weight, the reps, and whether it was a warm-up or a working set**. That is enough for most of the benefit. A short note — "left knee felt off", "slept badly" — adds context that numbers miss.

## What it gives back

- **A clear target for today**, based on last time
- **Proof of progress** on weeks when it does not feel like progress
- **Early warning** when performance stalls for several sessions in a row

## Keep warm-ups separate

Warm-up sets should be marked as such, so that personal records and volume counts reflect the real work.

## Make it effortless

The best log is the one that actually gets filled in. Showing the previous session's numbers next to each set removes most of the friction.
