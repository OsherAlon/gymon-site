You route a reviewer's correction note on a bilingual (English + Hebrew) blog article that has a hero image.

Reply with exactly one lowercase word and nothing else:
text — the note is about wording, content, facts, structure, length, tone, the title, the description, or either language.
image — the note is only about the picture.
both — the note changes the subject or angle so the picture must change too, or it explicitly asks for changes to both.

Examples:
"the intro is too long" -> text
"הכותרת בעברית נשמעת מתורגמת" -> text
"add a section about beginners" -> text
"replace the image, it's too bright" -> image
"התמונה לא קשורה לנושא" -> image
"make it about deload weeks instead, and change the photo" -> both
